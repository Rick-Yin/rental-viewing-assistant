# 页面级交互规格

本文档覆盖 checklist 列表页和详情页之外的页面交互规格。checklist 相关页面（第 5/6/10/11 页）详见 [checklist-ui-design.md](./checklist-ui-design.md)。

---

## 1. 租房画像与模板推荐页

### 页面元素

- 返回/跳过按钮（顶部导航栏）
- 进度指示器（当前步骤/总步骤）
- 画像表单区域
- 推荐结果展示区域
- 确认按钮

### 表单字段

| 字段 | 类型 | 选项 | 默认值 |
|------|------|------|--------|
| 租房身份 | 单选 | 大学生 / 在职人员 / 家庭 / 陪读 / 病人陪床 / 其他 | 未选 |
| 性别 | 单选 | 女 / 男 / 其他 / 不填写 | 不填写 |
| 同住情况 | 单选 | 独居 / 情侣 / 室友合租 / 家庭同住 / 陪护同住 | 未选 |
| 宠物 | 单选 | 无宠物 / 有宠物 / 未来可能养 | 无宠物 |
| 子女 | 单选 | 无孩子 / 有孩子 / 陪读相关 | 无孩子 |
| 特殊用途 | 多选 | 陪读 / 病人陪床 / 短租过渡 / 长期稳定 / 远程办公 | 空 |
| 所租地区 | 文本输入 | 自由输入 | 空 |

### 交互流程

1. **首次进入**：展示欢迎文案 + 开始按钮
2. **画像填写**：逐字段展示，支持跳过整个步骤
3. **推荐结果**：展示推荐的模板模块列表，每个模块显示 label + 推荐原因
4. **手动调整**：用户可以勾选/取消每个模块
5. **确认**：保存为 `ChecklistTemplateSelection`，进入房源列表

### 状态流转

```
首次进入 → 画像填写（可跳过） → 推荐结果 → 用户调整 → 确认 → 房源列表
```

### 跳过行为

- 点击"跳过"直接进入房源列表
- 使用默认模板组合（所有 alwaysEnabled 模块）
- 用户可在设置中随时重新填写

## 2. 房源列表页

### 页面元素

- 顶部：App 标题 + 设置入口
- 筛选/排序栏（可选）
- 房源卡片列表
- 底部：新增房源 FAB（浮动按钮）

### 房源卡片信息

```
┌─────────────────────────────────────────┐
│  阳光花园 2室1厅           [看房中]      │
│  ¥3,500/月  押一付三                     │
│  6/18层  南向  68.5m²                     │
│  最近看房: 05-11  风险: 1 ⚠  不确定: 1 ?  │
│  总分: 83                                 │
└─────────────────────────────────────────┘
```

### 状态标签

| status | 标签 | 颜色 |
|--------|------|------|
| draft | 草稿 | 灰色 |
| to_view | 待看房 | 蓝色 |
| viewed | 已看房 | 蓝色 |
| shortlisted | 候选 | 绿色 |
| signing | 签约中 | 橙色 |
| signed | 已签约 | 绿色 |
| signing_abandoned | 签约放弃 | 灰色 |
| rejected | 已排除 | 红色 |

### 交互

- **点击卡片** → 进入房源详情页
- **长按卡片** → 弹出操作菜单（编辑 / 删除 / 改变状态）
- **FAB 点击** → 进入新增房源页
- **筛选**：按状态分组显示
- **排序**：按总分降序 / 按创建时间 / 按租金

### 签约中状态提示

当已有房源处于 `signing` 状态时：
- 该房源卡片顶部显示"签约中"高亮条
- 其他房源的"进入签约"按钮禁用，tooltip 提示"已有房源在签约中"

## 3. 新增/编辑房源页

### 页面元素

- 返回 + 保存按钮（顶部导航）
- 表单字段

### 表单字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 房源标题 | 文本 | 是 | 如"阳光花园 2室1厅" |
| 小区名称 | 文本 | 否 | |
| 地址 | 文本 | 否 | 支持粘贴 |
| 区县 | 文本 | 否 | |
| 月租 | 数字 | 否 | 单位：元 |
| 押付规则 | 文本 | 否 | 如"押一付三" |
| 中介费 | 数字 | 否 | 单位：元 |
| 户型 | 文本 | 否 | 如"2室1厅1卫" |
| 面积 | 数字 | 否 | 单位：m² |
| 楼层 | 文本 | 否 | 如"6/18层" |
| 朝向 | 单选 | 否 | 南/北/东/西/东南/西南/东北/西北 |
| 联系人 | 文本 | 否 | |
| 电话 | 文本 | 否 | |
| 来源平台 | 单选 | 否 | 贝壳/自如/其他/手动 |
| 房源链接 | 文本 | 否 | |

### 交互

- **保存**：创建 Property 记录，status 默认为 `draft`，跳转到房源详情
- **编辑模式**：预填已有数据，保存后更新记录
- **来源平台选择"贝壳"**：提示用户可粘贴房源链接

## 6. 多房源对比板

### 页面元素

- 顶部：对比房源数 + 筛选条件
- 对比表格/卡片
- 底部操作区

### 对比维度

| 维度 | 数据来源 | 展示形式 |
|------|----------|----------|
| 月租 | Property.rentAmount | 数字 |
| 总分 | ScoreCard.totalScore | 进度条 |
| 交通 | ScoreCard.transportScore | 进度条 |
| 环境 | ScoreCard.environmentScore | 进度条 |
| 户型 | ScoreCard.layoutScore | 进度条 |
| 设施 | ScoreCard.facilityScore | 进度条 |
| 风险 | ScoreCard.riskScore | 进度条 |
| 性价比 | ScoreCard.pricePerformanceScore | 进度条 |
| 风险项 | ViewingChecklistResult 聚合 | 计数 |
| 不确定项 | ViewingChecklistResult 聚合 | 计数 |

### 交互

- **点击房源列** → 进入房源详情
- **长按房源列** → 弹出操作菜单（标记候选 / 排除 / 进入签约）
- **拖拽排序**（可选）→ 用户手动调整优先级
- **"进入签约"按钮** → 对选中的房源执行签约切换

### 空状态

- 未添加任何房源到对比：显示引导文案"添加房源到对比后可查看"
- 房源不足 2 套：显示"至少需要 2 套房源才能对比"

## 9. 签约 AI 审查结果页

### 页面元素

- 顶部：返回 + 分享按钮
- 总体建议区
- 关键风险区
- 待确认条款区
- 谈判建议区
- 必须补齐材料区
- 维度评估区

### 总体核查区

```
┌─────────────────────────────────────────┐
│  核查状态: 签约前需确认                  │
│                                         │
│  合同整体可接受，但维修责任和违约条款     │
│  需要补充明确后再签约。                   │
└─────────────────────────────────────────┘
```

| overallRecommendation | 展示样式 |
|----------------------|----------|
| can_sign | 绿色 ✓ 未发现明显阻断项 |
| clarify_before_sign | 黄色 ⚠ 建议确认后再签 |
| do_not_sign | 红色 ✗ 存在明显阻断项 |

### 关键风险区

```
┌─────────────────────────────────────────┐
│  关键风险 (2)                            │
│                                         │
│  ⚠ 高  维修责任未明确                   │
│  合同只写"租客负责保管使用"，未写明       │
│  房东的维修义务和响应时限。               │
│                                         │
│  ⚠ 中  违约金不对等                     │
│  只写了租客违约金，未写房东违约赔偿。     │
└─────────────────────────────────────────┘
```

### 待确认条款区

- 列出 missingClauses 中的每一条
- 每条可点击跳转到对应签约 checklist item

### 谈判建议区

- 列出 negotiationPoints 中的每一条
- 每条可复制

### 必须补齐材料区

- 列出 requiredFollowUps 中的每一条
- 每条可标记为已完成

### 维度评估区

| 维度 | 状态 | 说明 |
|------|------|------|
| 身份与授权 | ✓ 通过 | ... |
| 付款条款 | ⚠ 需确认 | ... |
| 租期与退租 | ⚠ 风险 | ... |
| 维修责任 | ✗ 缺失 | ... |
| 费用边界 | ✓ 通过 | ... |
| 承诺与附件 | ⚠ 需确认 | ... |

## 10. 设置页

### 页面元素

- 租房画像管理入口
- 模板组合管理入口
- 数据导出入口
- 数据备份/恢复入口（后续）

### 交互

- **租房画像** → 进入画像编辑页（同第 1 页，但预填已有数据）

- **导出数据** → 生成 manifest JSON → 分享/保存

## 全局交互规则

### 离线提示

- 所有功能在离线状态下可用
- AI 相关功能需要网络时提示"需要网络连接"

### 数据自动保存

- checklist 结果在用户点击 OK/Risk/Uncertain 时立即保存
- 备注在用户离开输入框时保存
- 不需要手动"保存"按钮

### 返回行为

- 系统返回键：回到上一页
- 数据已修改未保存时：弹出"是否保存"对话框
- checklist 页返回：回到房源详情

### 空状态设计

| 页面 | 空状态展示 |
|------|-----------|
| 房源列表 | "还没有房源，点击 + 开始添加" |
| 看房记录 | "还没有看房记录，点击下方按钮开始" |
| 对比板 | "添加房源到对比后可查看" |
| 签约材料 | "还没有签约材料，点击 + 添加" |
| AI 审查结果 | "还没有 AI 审查结果，点击按钮生成" |
