# 信息架构与页面树

## 目标

本文档定义 MVP 的页面树、阶段流转和关键页面职责，确保后续 Android 实现不再依赖口头约定。

## 阶段模型

产品包含两个阶段：

- `看房阶段`：多套房源并行记录、评分、对比
- `签约阶段`：仅一套房源进入活跃签约核查流程

## 房源状态

建议使用以下状态：

- `draft`
- `to_view`
- `viewed`
- `shortlisted`
- `signing`
- `signed`
- `signing_abandoned`
- `rejected`
- `archived`

说明：

- `shortlisted` 表示该房源仍处于看房阶段，但值得继续比较。
- `signing` 表示该房源已进入签约核查阶段。
- 同一时间只允许一套房源处于 `signing`。

## 页面树

### 1. 租房画像与模板推荐页

职责：

- 在用户选择模板前收集轻量租房画像
- 支持跳过、稍后填写和后续修改
- 根据画像推荐看房 checklist 与签约 checklist 的模板组合
- 展示推荐原因，例如“女性独居增加夜间路线和门锁检查”“有宠物增加宠物条款核查”
- 支持用户手动增删推荐模块

### 2. 房源列表

职责：

- 展示所有房源
- 按状态分组
- 快速进入房源详情
- 显示当前是否已有活跃签约房源

### 3. 房源详情

职责：

- 展示房源基础信息
- 展示看房记录时间线
- 展示当前阶段
- 在满足条件时提供“进入签约阶段”入口

### 4. 看房记录编辑页

职责：

- 编辑一次 `Viewing`
- 填写看房事实、备注和现场印象
- 保存看房级别的摘要信息

### 5. 看房 checklist 页

职责：

- 顶部显示房源摘要卡片（租金、中介费、风险/不确定项计数、联系人、地址、地图入口）
- 编辑 `ViewingChecklistResult`
- 支持内置项和自定义补充项
- 默认加载用户已选择的模板组合
- 关联照片和备注
- 支持点击单个 item 进入详情页

### 6. 看房 checklist item 详情页

职责：

- 展示该 item 的检查技巧
- 展示常见风险信号和记录建议
- 展示参考链接
- 支持返回看房 checklist 页

### 7. 看房照片与备注页

职责：

- 管理 `ViewingMediaAsset`
- 绑定到看房记录或具体检查项

### 8. 多房源对比板

职责：

- 展示多套房源的比较结果
- 展示推荐推进的一套房
- 提供“进入签约阶段”动作

### 9. 签约总览页

职责：

- 展示 `SigningSession` 的当前状态
- 聚合签约 checklist、签约材料和 AI 审查结果
- 提供“已签约”“签约放弃”动作

### 10. 签约 checklist 页

职责：

- 顶部显示房源摘要卡片（租金、押金、风险/不确定项计数、联系人、地址、看房+签约双进度）
- 编辑 `SigningChecklistResult`
- 聚焦条款、费用、责任和承诺
- 默认加载用户已选择的签约模板组合
- 支持点击单个 item 进入详情页

### 11. 签约 checklist item 详情页

职责：

- 展示该签约 item 的核查技巧
- 展示常见风险信号和记录建议
- 展示参考链接
- 支持返回签约 checklist 页

### 12. 签约材料页

职责：

- 管理 `SigningMaterialAsset`
- 支持文字摘录与图片材料
- 将材料与签约检查项关联

### 13. 签约 AI 审查结果页

职责：

- 展示签约阶段 AI 回贴结果
- 突出关键风险、待确认条款和谈判建议

## 关键流转

### 看房阶段主链路

`租房画像与模板推荐 -> 房源列表 -> 房源详情 -> 看房记录 -> 看房 checklist -> 看房 checklist item 详情页 -> 看房 checklist -> 看房照片备注 -> 房源详情 -> 对比板`

### 签约阶段主链路

`对比板 -> 进入签约阶段 -> 签约总览 -> 签约 checklist -> 签约 checklist item 详情页 -> 签约 checklist -> 签约材料 -> 签约 AI 审查结果 -> 已签约 / 签约放弃`

## 关键约束

- 没有至少一条 `Viewing` 的房源不能进入签约阶段。
- 若已有一套房源处于 `signing`，其他房源不能再次进入 `signing`。
- `ComparisonEntry` 只属于看房阶段。
- 签约阶段的 AI 结果不参与多房源对比，只服务于签约审查。
- 租房画像必须可跳过，且用户可以在后续设置中修改模板组合。
- 性别、陪护、孩子、宠物等字段只用于本地模板推荐，不应作为外部分享或 AI 内容的默认输出。

## 首版不做

- 多套房源并行签约
- 签约后的入住准备页面
- 复杂个性化推荐算法
- PDF、录音和外链型材料管理
- 云端协作状态同步
