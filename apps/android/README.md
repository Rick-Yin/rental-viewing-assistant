# Android App

Android is the first implementation target for the project.

Planned responsibilities:

- on-site property record creation
- viewing checklist interaction
- viewing photo capture and linking
- multi-property comparison
- entering signing stage for one selected property
- signing checklist interaction
- signing text and image material capture
- AI quick share for viewing and signing
- AI result import for viewing and signing
- single-property diagnosis
- signing risk review
- final `signed` / `signing_abandoned` state tracking

Implementation details are intentionally not fixed yet.
