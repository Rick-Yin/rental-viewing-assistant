# 租房画像与找房偏好模板

## 使用说明

- 本文件是 checklist 模板推荐前的前置输入模板。
- 它不属于某一套房的看房 checklist，也不应该映射到单个房源的现场检查 item。
- 这些内容用于生成更合适的看房和签约模板组合，并影响后续评分权重。
- 当前只保持粗粒度字段，等看房和签约 item 确认后，再继续细化为表单字段和推荐规则。

## 租房画像

### 租房身份

- `code`: `tenant_type`
- `说明`: 用户当前以什么身份租房。
- `候选值`:
  - 大学生
  - 在职人员
  - 家庭
  - 陪读
  - 病人陪床
  - 其他
- `用于推荐`:
  - 大学生：合租、预算、中介费、押金风险优先。
  - 在职人员：通勤、夜间回家、网络、噪音、长期稳定性优先。
  - 陪读或家庭：学校距离、儿童安全、租期稳定、备案配合优先。
  - 病人陪床：医院距离、电梯、无障碍、安静、通风和紧急联系人优先。

### 性别与独居安全

- `code`: `gender_and_safety`
- `说明`: 仅用于本地安全和隐私提醒，不默认进入 AI 分享内容。
- `候选值`:
  - 女
  - 男
  - 其他
  - 不填写
- `用于推荐`:
  - 女性独居：夜间路线、楼道照明、门禁、门锁、监控、隐藏摄像头、房东进入规则优先。

### 同住情况

- `code`: `co_living_type`
- `说明`: 判断是独居、情侣、室友合租、家庭同住还是陪护同住。
- `候选值`:
  - 独居
  - 情侣
  - 室友合租
  - 家庭同住
  - 陪护同住
- `用于推荐`:
  - 合租：室友、公共区域、费用分摊、访客和卫生规则优先。
  - 家庭或陪护：电梯、楼层、周边配套、稳定租期优先。

### 宠物情况

- `code`: `pet_status`
- `说明`: 判断是否需要宠物友好房源和宠物条款。
- `候选值`:
  - 无宠物
  - 有宠物
  - 未来可能养宠物
- `用于推荐`:
  - 增加是否允许养宠、宠物押金、清洁费、损坏赔偿、地板材质、异味和隔音检查。

### 子女与陪读情况

- `code`: `children_status`
- `说明`: 判断是否需要儿童友好、陪读或学区相关检查。
- `候选值`:
  - 无孩子
  - 有孩子
  - 陪读或学区相关
- `用于推荐`:
  - 增加学校距离、道路安全、楼层、电梯、窗户防护、噪音、备案和入学材料配合。

### 特殊用途

- `code`: `special_purposes`
- `说明`: 租房是否存在特殊使用场景。
- `候选值`:
  - 陪读
  - 病人陪床
  - 短租过渡
  - 长期稳定居住
  - 远程办公
  - 宠物友好
  - 儿童友好
- `用于推荐`:
  - 远程办公：网络、手机信号、白天噪音、采光优先。
  - 短租过渡：押金、提前退租、转租和付款周期优先。
  - 长期稳定居住：续租、涨价、房东卖房带看和维修责任优先。

### 所租地区

- `code`: `rental_region`
- `说明`: 用户计划租住的城市、区县、商圈或片区。
- `候选值`:
  - 用户手动输入
- `用于推荐`:
  - 提示本地租赁备案、居住证、群租面积、非居住空间出租、资金监管和消防要求差异。

## 本轮找房偏好

### 预算与付款承受能力

- `code`: `budget_preference`
- `说明`: 用户对月租、押金、中介费和一次性付款的承受范围。
- `字段定义`:
  - `monthlyRentMax`：月租上限
    - 类型：范围滑块
    - 候选值：1000 / 1500 / 2000 / 2500 / 3000 / 4000 / 5000 / 不限
    - 默认：不限
  - `depositRule`：可接受的押付方式
    - 类型：单选
    - 候选值：押一付一 / 押一付三 / 押二付一 / 押二付三 / 都可以
    - 默认：都可以
  - `acceptAgencyFee`：是否接受中介费
    - 类型：单选
    - 候选值：接受 / 不接受 / 视金额而定
    - 默认：视金额而定
  - `acceptMultiMonthPayment`：是否接受一次性支付多个月租金
    - 类型：单选
    - 候选值：接受 / 不接受 / 可接受最多 3 个月 / 可接受最多 6 个月
    - 默认：不接受
  - `rejectRentLoan`：是否明确拒绝租金贷或分期
    - 类型：单选
    - 候选值：是，明确拒绝 / 不确定，需要了解 / 不在意
    - 默认：是，明确拒绝
- `用于推荐`:
  - `rejectRentLoan = 是`：启用 `signing.fund_security`，增加租金贷风险提醒
  - `acceptAgencyFee = 不接受`：启用 `viewing.agency_basics` 中的中介费核查强化
  - `depositRule` 不含"押二"：启用 `signing.payment_deposit` 中的押金条款强化

### 通勤和区域偏好

- `code`: `commute_region_preference`
- `说明`: 用户对通勤时间、交通方式和目标区域的要求。
- `字段定义`:
  - `commuteDestination`：目标通勤地（公司、学校或常去地点）
    - 类型：自由文本
    - 默认：空
  - `maxCommuteMinutes`：可接受的单程通勤时间
    - 类型：单选
    - 倍选值：30 分钟以内 / 45 分钟以内 / 60 分钟以内 / 不限
    - 默认：45 分钟以内
  - `transportMode`：主要交通方式
    - 类型：多选
    - 候选值：地铁 / 公交 / 骑行 / 步行 / 开车 / 不限
    - 默认：不限
  - `needNightSafety`：是否需要关注夜间回家安全
    - 类型：单选
    - 候选值：是，经常加班晚归 / 偶尔需要 / 不需要
    - 默认：偶尔需要
  - `mustNearFacility`：是否必须靠近特定设施
    - 类型：多选
    - 候选值：地铁站 / 公交站 / 医院 / 学校 / 公司 / 超市 / 都不必须
    - 默认：都不必须
- `用于推荐`:
  - `needNightSafety = 是`：启用 `viewing.personal_safety`，增加夜间路线、门禁、监控检查
  - `transportMode` 含"地铁"：在 transportScore 中提高地铁可达性权重
  - `mustNearFacility` 含"医院"：增加 `viewing.medical_access` 相关检查
  - `mustNearFacility` 含"学校"：增加 `viewing.child_friendly` 相关检查

### 房源形态偏好

- `code`: `property_type_preference`
- `说明`: 用户对整租、合租、楼层、朝向、电梯、房龄和装修的取舍。
- `字段定义`:
  - `rentalType`：整租或合租
    - 类型：单选
    - 候选值：整租 / 合租 / 都可以
    - 默认：都可以
  - `acceptableFloor`：可接受楼层
    - 类型：多选
    - 候选值：低楼层（1-3）/ 中楼层（4-8）/ 高楼层（9+）/ 顶楼 / 都可以
    - 默认：都可以
  - `needElevator`：是否必须有电梯
    - 类型：单选
    - 候选值：必须 / 高楼层时必须 / 不必须
    - 默认：高楼层时必须
  - `acceptNorthFacing`：是否接受朝北
    - 类型：单选
    - 候选值：接受 / 不接受 / 视城市气候而定
    - 默认：视城市气候而定
  - `acceptOldBuilding`：是否接受老旧小区（房龄 20 年以上）
    - 类型：单选
    - 候选值：接受 / 不接受 / 视具体情况
    - 默认：视具体情况
  - `acceptNewRenovation`：是否接受新装修（1 年以内）
    - 类型：单选
    - 候选值：接受 / 不接受 / 需要确认甲醛检测
    - 默认：需要确认甲醛检测
- `用于推荐`:
  - `rentalType = 合租`：启用 `viewing.co_living` 和 `signing.co_living_agreement`
  - `needElevator = 必须`：在 layoutScore 中提高电梯权重
  - `acceptNorthFacing = 不接受`：在 layoutScore 中提高朝向权重
  - `acceptOldBuilding = 不接受`：在 riskScore 中提高老旧小区相关检查权重
  - `acceptNewRenovation = 需要确认甲醛检测`：启用 `viewing.property_safety` 中的甲醛检查强化

### 生活方式红线

- `code`: `lifestyle_red_lines`
- `说明`: 用户明确不能接受的居住条件，触发时 checklist 对应项自动标为高优先级。
- `字段定义`:
  - `redLines`：不可接受的条件（多选）
    - 类型：多选
    - 候选值：
      - 严重噪音（临街、工地、高架旁）
      - 潮湿发霉
      - 商水商电
      - 合租人数超过 3 人
      - 不允许养宠物
      - 不允许办理居住证
      - 不允许换锁
      - 房东可随意进入
      - 没有独立电表
      - 燃气为罐装气
      - 手机信号很弱
    - 默认：全不选（无红线）
- `用于推荐`:
  - 选中"严重噪音"：`external_noise_sources` 的 priority 提升为 high
  - 选中"潮湿发霉"：`bathroom_mold_odor` 的 priority 提升为 high
  - 选中"商水商电"：`meter_network_baseline` 中水电类型检查的 priority 提升为 high
  - 选中"合租人数超过 3 人"：`co_living_rules` 的 priority 提升为 high
  - 选中"不允许养宠物"：启用 `signing.pet_clause`
  - 选中"不允许办理居住证"：启用 `signing.filing_local`
  - 选中"不允许换锁"：`privacy_security_risk` 中钥匙管理检查的 priority 提升为 high
  - 选中"房东可随意进入"：启用 `signing.entry_rules`
